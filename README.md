- 만든 기간: 2026-11-17 ~ 2026-11-18
- 만든 방법: AI 코딩 에이전트(Claude Code)와 함께, 요구사항 문서(`PRD.md`)를 단계별로 구현

## 왜 만들었나

매일 약을 챙기는 일이 생각보다 어렵습니다.

- "아까 먹었나?"가 기억나지 않을 때 확인할 방법이 없음
- 약판에 몇 알이 남아 있어야 정상인지 매번 계산해야 함
- 할 일, 병원 일정, 약 재고, 물 마신 양이 여러 앱에 흩어져 있음

그래서 내 생활에 딱 맞는 앱을 직접 만들었습니다. 다른 사람에게 배포할 목적이 아닌 **개인용 도구**입니다.

## 주요 기능

### ✓ 할 일
- 할 일 추가, 수정, 삭제, 완료 체크, 카테고리(업무 / 개인 / 공부) 필터
- 전체 · 카테고리별 진행률, 모두 끝내면 폭죽과 명언(한자 명언은 한자 · 음 · 뜻풀이)
- 마감일 D-day 표시(오늘 빨강, 내일 주황), 드래그로 순서 바꾸기
- 기한 지난 할 일 자동 정리
- 📌 중요 일정 D-day

### 💊 복약
- **"먹었나?" 확인 카드:** 기록이 있으면 복용 시각과 "지금 판에 ○알 있어야 정상"을, 없으면 먹었을 때와 안 먹었을 때의 알 수를 둘 다 보여줌
- 아침 / 저녁 복용 체크 → 약판 남은 알 수와 전체 재고 자동 차감
- 목표 시각 기준 제시간 / 늦음 / 이름 판정, 실제 먹은 시각 직접 입력과 수정
- 놓친 약의 마감 시각 안내, 두 번 복용 기록
- 복용률과 빠진 복용 목록(7일 ~ 1년)
- 약 재고가 3일분 이하이면 모든 탭 맨 위에 경고

### 📓 건강수첩
- 💧 수분 섭취: 병 용량 버튼, 하루 목표량, 달성 기록
- 혈압 · 맥박 · 몸무게 · 특이사항 기록, 키를 넣으면 BMI 자동 계산
- 혈압(대한고혈압학회), BMI(대한비만학회) 기준 판정
- 몸무게 그래프, 혈압 · 수분 표(7일 ~ 1년)

### 공통
- 🏥 외래 D-day를 모든 탭 맨 위에 표시
- 앱을 켤 때 중요 정보 카드(외래, 재고, 가까운 일정과 마감)
- 뒤로 가기 두 번으로 종료
- 전체 데이터 백업 파일 저장(휴대폰 공유 창) · 불러오기

## 기술

| 항목 | 내용 |
|---|---|
| 언어 | 순수 HTML, CSS, JavaScript (프레임워크, 라이브러리, 빌드 도구 없음) |
| 저장 | 브라우저 `localStorage` (휴대폰 안에만 저장, 서버 없음) |
| 앱 설치 | PWA: `manifest.json` + 서비스 워커(`sw.js`)로 홈 화면 설치, 오프라인 실행 |
| 배포 | GitHub Pages (`git push`하면 자동 반영) |

### 파일 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대, 하단 탭(할 일 / 복약 / 건강수첩) |
| `style.css` | 전체 스타일, 휴대폰 화면 대응 |
| `app.js` | 할 일, 탭 전환, 축하 카드 |
| `meds.js` | 복약, 복용 기록, 백업 |
| `health.js` | 건강수첩(수분, 혈압, 몸무게) |
| `dday.js` | 외래 · 중요 일정 D-day, 재고 경고, 중요 정보 카드 |
| `sw.js` | 오프라인 실행용 서비스 워커 |
| `PRD.md` | 요구사항 문서 (무엇을, 왜 그렇게 만들었는지) |

## 개인정보 원칙

이 저장소는 공개되어 있으므로 다음을 지킵니다.

- 약 이름, 복용량, 건강 수치는 **코드에 적지 않습니다.** 모두 앱 안에서 직접 입력하고 휴대폰에만 저장됩니다.
- 서버로 보내는 데이터가 없습니다. 백업 파일도 사용자가 직접 보관합니다.
- 복약 시각과 마감 기준은 제 의료진 안내에 맞춘 것이라, **다른 사람의 복약 지침으로 쓰면 안 됩니다.**

## 만든 과정

코드를 대강 아는 학부생이 AI 코딩 에이전트와 함께 만들었습니다.

1. 원하는 기능을 말로 설명하고 `PRD.md`에 요구사항으로 정리
2. 요구사항을 작은 단계로 나눔 (1단계: 화면 뼈대 → 2단계: 추가와 저장 → …)
3. 단계마다 구현 → 브라우저와 휴대폰에서 직접 확인 → 커밋
4. 휴대폰으로 실제로 쓰면서 불편한 점을 찾아 고침 (예: 폰에서만 백업 불러오기가 안 되던 문제, 버튼이 작아 누르기 어렵던 문제)
5. 결정이 바뀌면 날짜와 함께 `PRD.md`에 기록

자세한 요구사항과 결정 기록은 [`PRD.md`](PRD.md)에 있습니다.
